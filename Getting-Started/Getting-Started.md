## How Do I Use This Repository?

If you haven't already, clone this repository by following the command in the [Getting Started](https://github.com/ishaann-007/Linux-Fundamentals#-getting-started) section of the README.

The learning material is organised into numbered modules, each covering a specific set of commands or concepts.

### How to Approach Each Module

1. **Read the theory.** Understand what each command does and when it is useful.
2. **Practise the examples.** Run the example commands in your terminal and observe their output.
3. **Complete the exercises.** Try solving the exercises at the end of the module without looking at the answers.
4. **Review your solutions.** Compare your answers with those in the corresponding `answers` folder to check your understanding and learn alternative approaches.

The goal is to understand how and why commands work, not just memorise their syntax. Take your time with each module and experiment with the commands where it is safe to do so.

You can start by heading over to [Module 1](https://github.com/ishaann-007/Linux-Fundamentals/blob/main/Module1/User%20and%20Terminal%20Basics.md)!
